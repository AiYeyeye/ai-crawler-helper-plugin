# Security Policy

## Supported Versions

Only the latest release of `ai-crawler-helper-plugin` is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >=0.1.x | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of `ai-crawler-helper-plugin` and its users seriously. Because this extension operates with sensitive browser permissions (such as `debugger` and `cookies`), secure coding practices are strictly enforced.

If you discover a security vulnerability or sensitive data handling issue, please report it responsibly:

1. **Do NOT file a public issue.**
2. Please submit a private vulnerability report via **GitHub Security Advisories** on this repository (under the **Security** tab -> **Report a vulnerability**), or contact the maintainer directly at `supercomputing@agent.qq.com`.
3. Include detailed steps to reproduce the vulnerability, including browser version, target webpage, and expected vs actual behavior.

---

## Vulnerability Handling Timeline

- **Initial Response**: Within 48 hours of receipt.
- **Triage & Patch**: We will investigate, verify, and release a patch as quickly as possible.
- **Public Disclosure**: Once a fix is published, a security advisory will be released acknowledging the reporter (unless anonymity is requested).
